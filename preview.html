React useEffect Infinite Loop Kaise Fix Karein (in Hindi)

Category: Error Solving

React useEffect infinite loop kaise fix karein? Is detailed guide mein hum React hooks ke common error aur unke perfect solution ko step-by-step seekhenge.
⚡ Quick Answer: React useEffect infinite loop ka main kaaran hai dependency array ka sahi istemal na karna ya state update ke dauran effect trigger hona. Isse fix karne ke liye, apne useEffect hook ke dependency array [ ] ko check karein aur ensure karein ki state ka update direct loop create na kare.

Doston, kya aapke sath kabhi aisa hua hai ki aapne koi ReactJS application chalayi aur browser hang ho gaya? Console mein "Too many re-renders" ka error flash kar raha hai? Yeh darr aur pareshani har us developer ne jheli hai jo React components ke sath kaam karta hai. Aaj hum is error ko जड़ से खत्म करना सीखेंगे.

useEffect infinite loop क्या है और यह क्यों होता है?

Jab hum useEffect ka use karte hain, to React ko batana padta hai ki yeh effect kab run hona chahiye. Agar hum dependency array ([]) ko sahi se manage nahi karte, to React har render par useEffect ko fire karta hai. Agar us effect ke andar koi setState function call ho raha hai, to woh phir se re-render trigger karta hai, aur loop chalu ho jata hai.

useEffect infinite loop कैसे fix करें (Step-by-Step)?

Infinite loop ko fix karne ke liye humein kuch best practices follow karni chahiye:

  1. Dependency Array check karein: Agar aapka effect sirf component load hone par chalna chahiye, to empty array [] zaroor dein.
  2. State update logic: Agar state update zaroori hai, to ensure karein ki woh conditional ho.
  3. Functional updates ka use karein: setCount(prev => prev + 1) ka use karein taaki dependency array mein pura state object na daalna pade.
import { useState, useEffect } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    // Sahi tarika: sirf ek baar chalega
    console.log("Component mounted");
  }, []); 

  return <div>Count: {count}</div>;
}

Dependency Array के common pitfalls क्या हैं?

Kai baar hum galti se objects ya arrays ko dependency array mein daal dete hain. Yaad rakhein, JavaScript mein objects ka reference check hota hai, na ki value. Har render par naya object banta hai, jisse React ko lagta hai ki value badal gayi hai.

Best Practices for React Performance

Performance ko behtar banane ke liye hamesha official React documentation ko follow karein. Excessive re-renders se bachne ke liye useMemo aur useCallback ka sahi istemal karein. Jab aap MERN Stack projects par kaam kar rahe hote hain, to data fetching ke liye useEffect use karte waqt cleaning function ka use zaroor karein.

Frequently Asked Questions (FAQs)

Q1: Infinite loop ka pata kaise chale?
Browser console mein "Too many re-renders" ka error aaye toh samajh jayein ki useEffect infinite loop mein phans gaya hai.
Q2: Kya useEffect mein API call karte waqt dependency array jaruri hai?
Haan, agar aap empty array nahi denge, to API call har render par trigger hogi, jo server par load badhayegi.
Q3: Functional updates kya hote hain?
Ye state ko update karne ka tareeka hai jahan hum old state ki value access karte hain (e.g., prev => prev + 1), isse dependency array mein state variable ki jarurat nahi padti.
Q4: Kya main object ko dependency array mein daal sakta hoon?
Object ko directly daalne se bachein, kyunki reference change hone par loop chal sakta hai. Use JSON.stringify ya specific primitive values.
Q5: Error solving mein kya dikkat aati hai?
Aksar developers logic ko useEffect ke bahar nahi nikaalte, jis se purani state refer hoti rehti hai. Hamesha clean code likhein.
